# Shared runtime, diagnostics and deployment references

The primary CarPlay and broker runtime sources now have canonical owners in `modules/carplay/runtime/` and `modules/broker/runtime/`; navigation runtime is in `modules/navigation/runtime/`. **Unit and SD-package output paths retain `runtime/...`**; these repository relocations do not alter installer expectations. This remaining root runtime tree intentionally holds generic diagnostics, deployment session helpers and an experimental fixture. See the module READMEs and `docs/architecture/REPOSITORY_LAYOUT.md` for active source ownership. The scripts here are not a qualified installer.
