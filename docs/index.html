05 / METHODOLOGY

Reading the atlas

Capability ✓ means the public repository reports an implementation; ◐ means partial or experimental, ◇ means planned, × means explicitly unsupported and · means insufficient evidence. This is a code/repository study, not an official hardware compatibility list.

Cluster categorization groups real part numbers and broader display families for filtering. When the public sources omit an exact part number, the dataset does not invent one. MIB2 High/Harman (MHI2), Qualcomm (MHI2Q) and TechniSat/Preh Standard (MST2) have different software and video architectures.

Technical origin is documented per capability where public credits or source evidence exist. The original project authors retain their respective copyright and license terms. Some sources include licenses that cannot automatically be mixed with GPL-3.0 code; do not assume code-copy permissions from an atlas comparison.

Offline behavior: sorting, platform/cluster/evidence/capability filtering, repository links within the file, expandable profiles and this graph are native HTML/CSS features. Optional text search requires JavaScript and may be unavailable in restricted iOS file previews. External GitHub links require connectivity.
