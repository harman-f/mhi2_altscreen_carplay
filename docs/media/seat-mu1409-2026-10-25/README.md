# SEAT/CUPRA MU1409 cockpit photographs

Contributor-supplied photographs, authorized by the photographer for inclusion
in this repository and its pull request. Identifying JPEG metadata was removed;
the decoded image pixels are unchanged. These are parked-vehicle observations,
not panel-resolution measurements or proof of universal compatibility.

See [the target report](../../testing/SEAT_CUPRA_MU1409_VEHICLE_OBSERVATIONS.md)
for the configuration, limitations and captions. No menu preset is inferred
from a gauge layout alone: physical cockpit layout and selected phone ViewArea
are separate states.
