### What about Škoda MU1440 / AID 10.5?

For the user's **MHI2 Škoda MU1440 / P4526 + AID 790** the newly published omonob V3.2 still offers an **experimental exact-profile installer**, but the public release provides **no target-unit software install acceptance or complete wireless iPhone/VC acceptance** on MU1440. Nothing in the MU1367 vehicle acceptance or Qualcomm MHI2Q work may be transplanted as a compatibility claim. V3.2 is the newest omonob tagged release found as of this review. Keep test-only install state and vehicle-supported status separate; user should not assume safe installation over a modified unit without complete recovery.

### Has omonob finally released the native source?

**No complete receiver implementation and clean-source build toolchain are provided publicly as of this cutoff.** V3.2 explicitly states: *“No separate implementation-source archive or build tools are attached.”* This matters even though the GitHub repository is tagged GPL-3.0 and includes many shell scripts, C/Java historical material, packed executable/native binaries, manifests, and auto-generated Source code ZIP/TAR archives: GitHub generated archives mirror what is checked in, and cannot be assumed to rebuild undocumented frozen receiver/OEM/SDK components. Do not claim “no source whatsoever”, but distinguish **partial public files** from **the complete receiver source that would permit a reproducible MU1440 port**. The tomasz MU1367 integration tree contains real public adaptation code but credits the upstream omonob receiver and does not fill that gap.
