# Firmware / binary findings ↔ published Wireless CarPlay prototype source

> **Research cross-reference — experimental / not vehicle validated.** This page links the firmware components examined in reverse engineering to the **documentation** and the **42 project-authored source files** published in this repository. It is an index of evidence and related source, **not** a claim that the stock OEM binaries or iOS frameworks have been redistributed.

## Reading this matrix correctly

- **Binary under study** means a *stock firmware component used as static evidence*. The public repository contains **no OEM firmware binary dumps, Apple frameworks, proprietary decompilations, certificates or private key material**.
- **Published source** means *our own experimental C/H/INC/SH/Python files*, not reconstructed production OEM code.
- The published code is **not an end-to-end Wireless CarPlay implementation**. Bluetooth/iAP2 A-side work is unvalidated on the target vehicle; discovery identity, Controller Connect, Pair Setup/Verify, trusted peer storage, encrypted session and iAP-over-Control remain open.
- The repository also contains a **separate, vehicle-demonstrated Virtual Cockpit / Stream111 project**. Its proof does **not** establish Wireless CarPlay connectivity.
